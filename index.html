About me

I'm a full stack engineer with eight years at Société Générale, working on web applications used by teams in Paris, New York, London and Asia. I started on a pricing and risk-indicator platform and now work on STAR, a treasury platform that gathers transactions from many sources into one database.

I like code that the next person can read. That means tests that run on every change, refactoring done in small steps, and documentation written while the details are still fresh.

  • Used worldwide

    Applications relied on by several teams across Europe, the US and Asia.

  • Desktop to web

    Several modules migrated from a heavy client to the web application.

  • Quality built in

    Unit and integration tests, automated checks and regular code review.

  • Bilingual

    Fluent in French and English, and used to working with international teams.
